# 译喵开发入口

这是 macOS 14+ 原生 Swift 桌宠，Swift Package 无外部依赖。功能、运行方式及提交规范以 [README](../README.md) 为准；变更历史和验证边界以 [CHANGELOG](../CHANGELOG.md) 为准。当前为本地 `main` 分支，未配置远程；构建产物和密钥不纳入版本管理。

## 定位代码

- [SelectionWatcher.swift](../Sources/Yimiao/Translate/SelectionWatcher.swift)：读取选中文字和边界；AX 坐标转 AppKit 坐标必须使用主显示器顶边，不能使用当前活动显示器高度。
- [SelectionPlacement.swift](../Sources/Yimiao/Bubble/SelectionPlacement.swift)：纯几何避让，预留完整气泡范围；返回 `nil` 表示没有安全空位，禁止改为覆盖选区。
- [PetController.swift](../Sources/Yimiao/App/PetController.swift)：维护本次选区、跳跃及菜单栏无空位回退；[BubbleView.swift](../Sources/Yimiao/Bubble/BubbleView.swift) 根据窗口尺寸限制滚动正文。
- [AIServiceTests.swift](../Tests/YimiaoTests/AIServiceTests.swift)、[SelectionPlacementTests.swift](../Tests/YimiaoTests/SelectionPlacementTests.swift)：服务隔离与避让回归测试。

2026-10-15 决策：避让基于取词时的选区快照，流式输出不逐字移动气泡。可用空间不足先缩小并滚动，再尝试其他显示器，最终转菜单查看；不以遮挡原文换取悬浮显示。原生视图验证用 `swift run Yimiao --selection-layouts .build/selection-layouts.png`，因为 `ImageRenderer` 不会完整绘制原生滚动内容。
