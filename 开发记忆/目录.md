# 译喵开发入口

这是 macOS 14+ 原生 Swift 桌宠，Swift Package 无外部依赖。功能和运行方式以 [README](../README.md) 为准，提交规范以 [CONTRIBUTING](../CONTRIBUTING.md) 为准，变更历史和验证边界以 [CHANGELOG](../CHANGELOG.md) 为准。主分支 `main`，托管在 GitHub 的 Hannah-bbbb/AI-Translation-Desk-Pet；构建产物和密钥不纳入版本管理。

## 定位代码

- [SelectionWatcher.swift](../Sources/Yimiao/Translate/SelectionWatcher.swift)：读取选中文字和边界；AX 坐标转 AppKit 坐标必须使用主显示器顶边，不能使用当前活动显示器高度。
- [SelectionPlacement.swift](../Sources/Yimiao/Bubble/SelectionPlacement.swift)：纯几何避让，预留完整气泡范围；返回 `nil` 表示没有安全空位，禁止改为覆盖选区。
- [PetController.swift](../Sources/Yimiao/App/PetController.swift)：维护本次选区、跳跃及菜单栏无空位回退；[BubbleView.swift](../Sources/Yimiao/Bubble/BubbleView.swift) 根据窗口尺寸限制滚动正文。
- [PetBrain.swift](../Sources/Yimiao/Pet/PetBrain.swift)：姿势、扑鼠标（`Teasing` 识别来回晃）、打字、跳舞、电量；[Look.swift](../Sources/Yimiao/Pet/Look.swift)：毛色调色板、装扮与节日日期（农历用 `Calendar(identifier: .chinese)`）。
- [Surroundings.swift](../Sources/Yimiao/Support/Surroundings.swift)：音频输出是否在工作、电池、其他 App 的窗口位置（只读位置和归属，不读标题，无需屏幕录制权限）。
- [CatLifeTests.swift](../Tests/YimiaoTests/CatLifeTests.swift)：猫行为、⌥ 轻按、节日、每日统计、窗口座位。
- [AIServiceTests.swift](../Tests/YimiaoTests/AIServiceTests.swift)、[SelectionPlacementTests.swift](../Tests/YimiaoTests/SelectionPlacementTests.swift)：服务隔离与避让回归测试。

2026-10-15 决策：避让基于取词时的选区快照，流式输出不逐字移动气泡。可用空间不足先缩小并滚动，再尝试其他显示器，最终转菜单查看；不以遮挡原文换取悬浮显示。原生视图验证用 `swift run Yimiao --selection-layouts .build/selection-layouts.png`，因为 `ImageRenderer` 不会完整绘制原生滚动内容。

2026-10-16 决策：「像只猫」的行为都以真实信号为由头，每项可在设置里单独关。跳舞时帧率限到 60（`PetView.Pace.steady`），否则 CPU 会到 10% 左右。坐窗口只坐在窗口上沿之外，不遮挡窗口内容；被其他窗口挡住就离开，避免「浮在别的窗口上」。窗口占满屏幕时没有空间，这是预期行为。验证坐窗口时，Claude 桌面应用会反复回到前台盖住测试窗口，需要临时去掉遮挡判断才能测跟随移动。
